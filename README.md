# erik.day

My personal site — [erik.day](https://erik.day).

I'm a design engineer in Stockholm working on private, uncensorable money. HRF grantee on [Cashu](https://cashu.space), and Lead Designer at [Hoseki](https://hoseki.app).

## Stack

Next.js · React · TypeScript · Tailwind · shadcn/ui · Framer Motion, deployed on Vercel.

## Local development

```bash
pnpm install
pnpm dev
```

Site content lives in [`src/data/resume.tsx`](./src/data/resume.tsx).
